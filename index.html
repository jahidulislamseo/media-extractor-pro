Frequently Asked Questions

Direct answers to common questions about permissions and formats.

Is Media Extractor Pro completely free? ▾
Yes, Media Extractor Pro is 100% free and open-source under the MIT license. There are no subscriptions, feature limits, or locked tiers.
Does it work on Instagram, Pinterest, or Behance? ▾
Yes! It extracts all publicly embedded image tags, video elements, and background CSS URLs from dynamic websites.
Is my browsing data tracked or sent to any server? ▾
Never. Media Extractor Pro runs entirely inside your browser sandbox. It does not contain any analytics SDKs, external APIs, or remote data logging.
What file formats are supported? ▾
It detects PNG, JPG, JPEG, WebP, SVG, GIF, MP4, WebM, MP3, WAV, and standard embedded media streams.
