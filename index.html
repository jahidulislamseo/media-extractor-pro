Everything You Need to Harvest Media

Built completely with Chrome Manifest V3, zero external libraries required at runtime, and fully bundled with offline JSZip.

1-Click Offline ZIP Archiving

Bundles all selected images and videos into a single uncompressed or compressed ZIP file in memory using local JSZip 3.10.1. Never deal with 50 separate browser save prompts.

Deep Infinite-Scroll Engine

Scrape infinite-scroll feeds on Pinterest, Instagram, Unsplash, or e-commerce catalogs automatically with custom scroll speed and live extraction counters.

Audio & Podcast Extractor

Dedicated Audio tab detects embedded audio tags, background podcast streams, and voice notes with an integrated preview player directly inside the popup.

Dynamic Dimension Slider

Eliminate tiny tracking pixels, avatar icons, and layout spacers. Drag the slider to filter out anything below 300px or keep strictly 1080p and 4K assets.

Offline Canvas Converter

Convert modern web formats (WebP and AVIF) into universally compatible PNG or JPG formats directly on HTML5 Canvas without uploading your files anywhere.

Right-Click Context Menu

Extract all media from any page with one right-click or instantly download targeted video and image assets in their original source resolution.

100% Private, Local & Secure

Media Extractor Pro operates strictly inside your local browser. It never connects to third-party tracking APIs, transmits zero analytics, and inspects only the page you explicitly trigger.

Quick Start

Install in Less than 60 Seconds

Choose between the official Chrome Web Store installation or running unpackaged from GitHub.

1

Open Chrome Web Store

Click the Media Extractor Pro Store Listing.

2

Click "Add to Chrome"

Confirm the permission prompt to activate the extension on your active browser tab.

3

Pin to Toolbar & Extract

Click the Chrome puzzle piece 🧩 in your top bar, pin Media Extractor Pro, and click it on any page to start extracting.

1

Download Release ZIP

Click here to download media-extractor-pro-v2.0.0.zip and extract it on your desktop.

2

Open Chrome Extensions Manager

Navigate to chrome://extensions and toggle "Developer mode" in the top-right corner.

3

Click "Load Unpacked"

Click the "Load unpacked" button in the top-left and select the extracted folder containing manifest.json.
