Architectural Capabilities

Engineered for precise extraction without third-party network dependencies.

Native DOM Querying

Iterates across img, picture source, video, and audio tags. Parses background-image declarations across deeply nested CSS styling trees.

Resolution Thresholds

Filters out tracking pixels and UI avatars via integer pixel boundaries. Restricts downloads strictly to high-resolution master assets.

Bundled ZIP Compilation

Compresses media assets into an organized ZIP archive client-side with JSZip 3.10.1, eliminating individual browser download prompt spam.

Zero Data Collection

Operates strictly in an isolated client sandbox under Manifest V3. Does not initialize external analytics SDKs or remote telemetric trackers.

DOM Feed Automation

Simulates continuous viewport scrolling on dynamic feeds to trigger lazy-loaded resources across galleries without manual pagination.

Canvas Transcoding

Transcodes modern AVIF and WebP buffers into uncompressed PNG or standard JPG files directly through in-memory canvas contexts.

Operational Workflow

Three straightforward stages to inspect and package webpage media.

PHASE_01

Inspect Active Document

Launch the extension on any tab. The background script queries the document model and maps all visual element references.

PHASE_02

Calibrate Bounds

Apply minimum width and height sliders. The queue filters out small thumbnails and retains target visual resolutions.

PHASE_03

Compile ZIP

Initiate packaging. The client engine compresses the byte buffers into a consolidated archive within your local Downloads folder.

Frequently Asked Questions

Technical clarifications on permissions, storage, and file handling.

How does Media Extractor Pro package media without server latency? +
Media Extractor Pro bundles JSZip 3.10.1 directly inside the extension sandbox. All binary buffers are fetched locally via XMLHttpRequest or fetch within the active browser session, converted to binary Blobs, and compressed entirely on the client CPU without relaying bytes to third-party endpoints.
Does this extension bypass site authorization or access private user files? +
No. The extension inspects only publicly rendered DOM elements and active network resources already loaded in the document window. It adheres strictly to Chrome activeTab permissions and does not access private session credentials.
How does the dimension threshold filtering operate? +
The script queries the naturalWidth and naturalHeight properties of Image and Video elements. Any asset failing the defined pixel threshold (e.g. icons under 150px or tracking pixels) is discarded from the selection queue prior to download initiation.
