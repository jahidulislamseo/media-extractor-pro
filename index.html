Frequently Asked Questions

Direct answers to common questions about bulk media downloads and privacy.

How do I download all images from a webpage at once in Chrome? ▾
Install Media Extractor Pro from the Chrome Web Store, click the extension icon on any page, and select Download All Selected (ZIP). All images are packaged into a single ZIP file on your computer without multiple download prompts.
Can I filter out small logos, icons, and tracking pixels? ▾
Yes. Media Extractor Pro includes an interactive dimension slider. You can set minimum width and height thresholds (e.g., > 200px or > 1080p) to automatically exclude small icons and keep only high-resolution photos and videos.
Does Media Extractor Pro work on infinite scroll websites like Instagram and Pinterest? ▾
Yes. Version 2.0 includes an Auto-Scroll and Deep Scraper engine that automatically scrolls dynamic feeds at customizable speeds to collect and parse all media elements.
Is Media Extractor Pro safe and private? ▾
Yes, 100%. Media Extractor Pro is built under Google Manifest V3 standards. All scanning, canvas conversions, and ZIP packaging happen entirely client-side in your browser. No data or media URLs are ever sent to external servers.
