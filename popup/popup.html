About Media Extractor Pro
Media Extractor Pro
Version 1.1.0  ·  Manifest V3

A powerful browser extension that instantly detects and extracts all images and videos from any webpage. Works 100% locally — no data is ever uploaded.

✨ Features
  • 🖼️ Extract JPG, PNG, GIF, WEBP, SVG, AVIF, BMP, ICO
  • ⚡ Inline SVG extraction & raw source code copy
  • 🎥 Detect standard MP4, WEBM, and OGV videos
  • 🔍 Filter by format, size & keyword search
  • 📊 Export Alt Text & media metadata to CSV sheet
  • 🔗 1-Click format conversion via UnifiedTools Pro
  • ⏳ Live download progress tracking indicator
  • 📋 Copy any media URL with one click
  • 🔒 100% local — no account, no tracking, no uploads
